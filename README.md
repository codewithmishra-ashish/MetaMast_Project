# Fee Payment & Scholarship Contract System

## 📌 Project Title
Fee Payment & Scholarship Contract System

## 📘 Project Description
This project is a decentralized Fee Management and Scholarship Allocation System built on Ethereum using Solidity.  
It allows an educational institution to register students, collect fee payments securely, and grant scholarships — all recorded transparently on the blockchain.

The system ensures immutability, removes intermediaries, and provides trustless verification of fee-related records.

---

## 🎯 Project Vision
To create a fully transparent, tamper-proof, decentralized financial management system for educational institutions, where all fee payments, student registrations, and scholarship awards are stored securely on the blockchain.

---

## ⭐ Key Features

### **1. Student Registration**
- Admin registers students with predefined total fees.
- Ensures only valid students can use the system.

### **2. Fee Payment**
- Students pay fees directly to the smart contract using the `payFees()` payable function.
- Prevents overpayment using strict checks.

### **3. Scholarship Granting**
- Admin can grant scholarships to eligible students.
- Scholarship status is permanently stored on-chain.

### **4. Transparent Records**
- Anyone can view student details (fees paid, remaining fees, scholarship status).

### **5. Secure Role-Based Access**
- Only admin (contract deployer) can register students and assign scholarships.
